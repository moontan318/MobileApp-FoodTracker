# Meal Macros

An Android app for building recipes from weighed ingredients and working out the
nutrition in whatever portion you eat.

* **Recipes**: add ingredients with their weights. Search the built-in database of
  8,789 foods (USDA SR28, works offline) or enter your own foods from a nutrition
  label.
* **Portions**: enter the weight you're eating and the app scales every ingredient.
  For example, a recipe of 200 g potatoes + 200 g beef (400 g total) eaten as a 200 g
  portion shows the nutrition of 100 g potatoes + 100 g beef.
* **Cooked weight** (optional): weigh the finished dish so portions account for water
  lost or gained during cooking.
* **Detailed nutrition**: energy (kcal and kJ), protein, carbohydrates, fibre, sugars,
  fat (saturated, mono, poly), cholesterol, water, 13 vitamins (A, C, D, E, K, B1, B2,
  B3, B5, B6, folate, B12, choline) and 10 minerals (calcium, iron, magnesium,
  phosphorus, potassium, sodium, zinc, copper, manganese, selenium), each with a
  % daily value.
* **Sizes as well as weights**: 15,000+ household measures from USDA, so you can
  add "1 medium banana" (118 g), "2 large eggs" or "1 cup cooked rice" without
  weighing. Your own foods can have a portion too (e.g. "1 bar = 45 g").
* **Food diary**: log recipe portions or individual foods (by weight or size) to
  any day and see daily totals.

## Installing on an Android phone

Every push is built by GitHub Actions (`.github/workflows/android.yml`).

1. Download `MealMacros.apk`:
   * from the repository's **Releases** page (a new release is published for every
     push to `main`), or
   * from the **Actions** tab: open the latest "Build Android APK" run and download
     the `MealMacros-apk` artifact (a zip containing the APK).
2. Open the APK on the phone. When prompted, allow your browser or file manager to
   install unknown apps.

Requires Android 8.0 (API 26) or newer. Every build is signed with the same key
(`app/signing.keystore`), so a newer APK installs over an older one and keeps your
data.

## Building locally

Requires JDK 17 and the Android SDK (API 35).

```sh
./gradlew :app:assembleRelease      # APK in app/build/outputs/apk/release/
./gradlew :core:test                # nutrition engine unit tests
./gradlew -PcoreOnly :core:test     # the same, on a machine without the Android SDK
```

## Project layout

* `core/`: pure Kotlin nutrition engine (nutrient definitions, food database
  parsing and search, recipe/portion calculations) with unit tests.
* `app/`: Android app (Jetpack Compose UI and JSON storage in app-private storage).
* `app/src/main/assets/usda_sr28.tsv` and `usda_portions.tsv`: food composition
  data and household measures, generated by `tools/build_food_db.py` from the USDA
  National Nutrient Database for Standard Reference, Release 28 (public domain).

Daily values are the FDA adult reference values (2,000 kcal diet). Nutrition figures
are estimates for guidance only.
